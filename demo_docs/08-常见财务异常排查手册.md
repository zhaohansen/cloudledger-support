# 常见财务异常排查手册

> 适用版本：全版本通用 ｜ 文档类型：常见问题

## 1. 数电发票验真提示「查验不一致」或「查无此票」

按以下顺序核查：
1. **当日新开发票延迟**：销售方刚开具的数电发票同步至税局查验库通常有 5–30 分钟延迟，建议半小时后重新点击「重新验真」；
2. **含税与不含税金额填反**：手工录入查验时，数电发票需填写「价税合计（小写）」而非不含税金额；
3. **票号位数截断**：数电发票号码固定为 20 位纯数字，若通过旧版 Excel 打开导致末尾变成 `00000`（科学计数法失真），请直接上传原件 XML 文件。

## 2. 预算执行流水与部门可用额度对不上

如果「预算中心」显示的可用预算余额，与「初始预算 - 预算执行流水汇总」不一致：

1. 在「预算管理 → 预算流水」按成本中心和费用科目筛选，核对各笔占用与释放记录；
2. 检查是否存在处于「草稿」（v2.2）、「审批中」或「银企支付退票未冲销」状态的单据——这类单据尚未进入最终支出实绩，但仍占用冻结额度；
3. 检查是否有人通过数据库后台手工修改过单据状态（严禁绕过应用层直接改库）；
4. 由财务管理员在「预算管理 → 额度重算」发起预算占用结存重算任务。**注意**：额度重算只根据有效单据重新汇总占用与剩余可用额，不会删除任何预算流水；执行前请先备份业务数据库。

## 3. 月度关账后提示「会计期间已锁定」

企业完成当月结账锁期后，任何归属该月的报销单审核、凭证生成都会被拦截：
- 常规跨月补报：将报销单的「入账会计期间」改为当前开放月份（开票日期仍保留真实开票日）；
- 确需调整已关账月份账务：须由财务经理在「总账协同 → 会计期间管理」提交**反结账**操作，补完单据并更新凭证后重新关账。

## 4. 单据审核或反审核失败

常见原因：
- 单据状态已被其他财务人员先行审核或退回（并发操作冲突）；
- 当前操作人没有该成本中心或法人主体的财务复核权限；
- 对应预算池剩余额度不足（针对提交/终审环节）；
- 单据缺少必填的进项税抵扣勾选标识或项目辅助核算项。
建议刷新单据详情页核对最新状态后再提交，切勿连续重复点击审核按钮。
