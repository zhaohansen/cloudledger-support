# 数电发票池与验真规范

> 适用版本：全版本通用 ｜ 文档类型：操作手册

## 1. 支持的发票版式与采集方式

云账费控系统支持全面数字化的电子发票（数电发票）及增值税普通发票、专用发票入池管理：

- **XML 原生文件（推荐）**：直接解析国家税务总局标准电子发票 XML 结构化标签，无需依赖图像识别，税额、购买方纳税人识别号、项目明细准确率最高。
- **OFD / PDF 版式文件**：解析电子签章信息与版式文本层；若 PDF 为打印后重新扫描的图片件且无文本层，系统会提示「未检测到有效文本层，请上传税务数字账户导出的原件」。

操作路径：`发票管理 → 企业发票池 → 上传票据`。

## 2. 税务验真与抬头合规校验

票据进入发票池时自动执行三项合规核验：

1. **四要素真伪查验**：核对 20 位数字数电发票号码、开票日期、价税合计金额及购买方统一社会信用代码，查验状态必须为「正常」。
2. **抬头与税号强校验**：购买方名称与纳税人识别号必须与当前租户企业主体完全一致；个人抬头发票仅允许关联通讯补贴等明确豁免的费用类型。
3. **发票状态拦截**：查验结果为「已红冲」「已作废」或「失控」的发票，系统自动标红拦截，禁止关联任何报销单或对公付款单。

## 3. 发票查重与防重复报销

系统以 **20 位数字数电发票号码**（传统税控票为发票代码 + 发票号码）建立全局唯一查重锁：

- **草稿关联锁定**：发票一旦关联到某张报销单，状态由「未使用」变为「占用中」，其他员工再次上传同一张发票会提示「该发票已被报销单占用，不可重复报销」。
- **驳回或撤回释放**：只有当原报销单被驳回并解除票据关联，或报销草稿删除后，发票状态才会恢复为「未使用」。

## 4. 红字信息确认单与红冲处理

已入账或已认证抵扣的数电发票发生退货、开票有误或服务中止时：

1. 财务人员需先在电子税务局或系统「税务协同 → 红字信息确认单」发起或确认红字申请；
2. 取得红字数电发票后，在「发票管理 → 红冲核销」将蓝字原票与红字发票配对；
3. 若原蓝字发票已生成总账凭证，必须先走冲销凭证流程，严禁直接物理删除已入账发票记录。
