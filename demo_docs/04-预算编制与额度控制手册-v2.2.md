# 预算编制与额度控制手册（v2.2）

> 适用版本：仅适用于产品版本 v2.2 ｜ 文档类型：操作手册

## 1. 预算控制入口

v2.2 的操作路径：`预算管理 → 部门预算 → 额度控制`。

财务预算管理员按年度或季度为各成本中心与费用科目下达预算池。在 v2.2 版本中，员工新建报销单并保存草稿后，系统会立即按草稿金额预占冻结该部门的可用预算额度，防止多人同时填单导致提交时超支。

## 2. 预算编制与导入方式

部门预算支持两种录入方式：

1. 在「预算管理 → 部门预算 → 新建预算单」手工逐科目填写各月度预算金额；
2. 在「预算管理 → 部门预算 → 导入预算表」下载 Excel 模板，填写后上传。

导入模板的列顺序为：成本中心编码、费用科目编码、预算期间、预算金额。模板版本必须为 v2.2 专用模板，若混用 v2.3 模板会提示「模板版本不匹配」。

## 3. 预算调整与审核生效

保存预算调整单后，系统计算调整前额度与调整后额度的差额。经财务总监审核通过后：

- 预算调增生成预算追加记录，立即可用；
- 预算调减不得低于当前「已使用 + 已冻结」之和，否则无法审核；
- 预算单状态变为「已审核」，不能直接修改；如需变更需先执行**反审核**或新建预算调整单。

## 4. v2.2 版本的限制

- 报销草稿保存即冻结预算：若员工长期不提交且不删除草稿，部门可用预算会持续减少；需要申请人删除草稿或由部门管理员执行草稿清理后才能释放额度。
- 不支持报销超预算时一键拉起预算追加单，必须由预算员手工新建预算调整单。
- 不支持移动端拍照 OCR 自动识票。
- 单次导入预算明细最多 3000 行。

## 5. 常见报错

- 「存在未审结的跨期结转单」：请先完成上一期间的预算结转审核。
- 「费用科目未纳入该成本中心」：导入表包含未授权给该部门使用的费用科目。
- 「预算金额格式错误」：金额列存在文本字符、千分位逗号或空值。
