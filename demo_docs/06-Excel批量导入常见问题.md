# Excel 批量导入常见问题

> 适用版本：全版本通用 ｜ 文档类型：常见问题

## 1. 提示「模板版本不匹配」

原因：不同产品版本的费用科目映射表、期初预算导入模板列结构不同（例如 v2.3 新增了「项目维度编码」与「进项税抵扣标识」列）。

处理步骤：
1. 进入对应模块（如「基础资料 → 费用科目 → 导入」或「预算管理 → 导入预算表」），重新点击「下载当前版本标准模板」；
2. 不要直接修改旧版本模板的表头文字后强行上传；
3. 将数据以「仅粘贴数值」方式复制到新模板后保存为 `.xlsx` 重新导入。

## 2. 提示「科目编码重复」或「项目编码重复」

常见原因与排查：
1. **首尾隐藏空格或不可见字符**：从 ERP 或聊天软件复制编码时带入了全角空格、换行符，系统去重清洗时判定冲突；建议在 Excel 中用 `TRIM()` 清理；
2. **与已停用档案重名**：系统中存在同名但处于「已停用」状态的费用科目或项目编码（默认列表不展示停用项），需勾选「显示已停用」核查；
3. **本次表格内部重复**：同一份 Excel 中出现两行相同编码。

## 3. 导入失败如何查看具体错误行

- **v2.2 版本**：导入校验失败时，弹窗仅提示报错行号（如「第 12 行校验未通过」），需人工对照模板逐列检查必填项、编码规则和金额小数位。
- **v2.3 版本**：校验失败后支持点击「下载错误原因明细表」，导出的 Excel 会在最后一列逐行标注错误行具体错误原因（如「第 15 行：成本中心编码不存在」「第 23 行：税率不在允许范围」），修正后可直接重传。
