# 差旅与日常费用报销手册

> 适用版本：全版本通用 ｜ 文档类型：操作手册

## 1. 标准费用报销流程

标准流转链路：`员工填报 → 关联数电发票 → 提交审批（部门负责人 → 财务复核）→ 出纳银企付款 → 生成总账凭证`。

1. 在「费用报销 → 新建报销单」选择费用大类（差旅费、招待费、研发耗材、行政办公等）与归属成本中心。
2. 从个人发票池勾选已验真通过的发票，系统自动带出不含税金额、税率与进项税额。
3. 核对收款账户信息与预算占用提示，点击「提交审批」。
4. 部门负责人审批业务真实性，财务复核岗审核票据合规性与费用科目，审核通过后进入出纳待付款队列。

## 2. 差旅标准控制与超标说明

- 系统按员工职级与出差城市等级自动匹配住宿、交通补贴上限。
- 若实际填报金额高于差旅标准，单据会触发「超标预警」标签：
  - **柔性控制模式**：允许提交，但必须填写超标原因并自动加签分管领导审批；
  - **刚性拦截模式**：直接阻断提交，需拆分个人承担金额后方可送审。

## 3. 已审核报销单反审核与修改

报销单经财务复核通过后，金额、税额与归属部门即锁定，员工不能自行修改。若发现费用科目挂错或税额拆分有误：

1. 先检查单据下游状态：**尚未发起银企直连打款，且尚未推送生成 ERP 总账凭证**；
2. 由具备「财务复核」权限的账号进入「费用报销 → 单据查询 → 报销单详情」，点击「反审核」并填写反审核原因；
3. 反审核成功后，单据退回待复核或退回申请人修改，同时记录审计留痕；
4. 若单据已发起付款或已生成记账凭证，系统会拒绝反审核并提示「存在下游付款批次或记账凭证，请先撤回付款或冲销凭证」。

## 4. 常见填报报错

- 「价税合计与报销申请金额不一致」：报销明细金额不得大于所关联发票的票面价税合计。
- 「缺少必填辅助核算项」：研发或项目制费用必须选择具体项目编码。
- 「当前会计期间已关账」：归属月份已完成财务月结，需改选当前开放期间或联系财务总账岗处理。
