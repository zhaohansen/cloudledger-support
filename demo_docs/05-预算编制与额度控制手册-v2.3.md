# 预算编制与额度控制手册（v2.3）

> 适用版本：仅适用于产品版本 v2.3 ｜ 文档类型：操作手册

## 1. 预算中心升级与冻结时机调整

v2.3 将原「部门预算」模块升级为「预算中心」，操作路径：`预算管理 → 预算中心 → 额度策略`。

与 v2.2 相比，核心控制时机发生了重要调整：

- **v2.2 旧规则**：员工新建报销单点击「保存草稿」即冻结部门可用预算；
- **v2.3 新规则**：保存报销草稿**不再冻结可用预算**，只有员工正式点击「提交审批」时才校验并冻结对应预算额度，彻底解决员工积压草稿占满部门预算的问题。

支持按部门、专项研发项目、季度滚动池三维联合控制。

## 2. 票据采集与预算联动（含移动端拍照 OCR）

v2.3 在报销填单与票据采集环节新增两项能力：

1. **数电票 XML 原生导入**：自动提取票面金额并实时试算当前部门剩余可用预算；
2. **移动端拍照 OCR 识票**：支持员工用手机拍摄纸质火车票、出租车票或数电票版式截图，通过 OCR 自动识别金额、开票日期与发票号码并入池查重。

## 3. 预算超支处理与一键追加调整单

当报销单提交审批发现可用预算不足时：

1. 若科目配置为「刚性控制 + 允许申请追加」，页面会弹出「一键生成预算追加单」入口；
2. 点击「生成追加单」后，系统按超支差额自动生成一张关联预算调整单；
3. **注意生效条件**：生成的预算追加调整单必须经过预算管理员与财务负责人**二次审核通过后**，新增预算额度才会正式写入可用池，此时原报销单方可继续推进审批。

## 4. 预算执行对账与核销

- 单据提交审批时：计入「审批冻结额度」；
- 审批驳回或撤回时：自动解除冻结，额度回到「可用预算」；
- 银企直连付款成功（或线下标记已付）后：由「审批冻结额度」转为「已执行实绩」。
