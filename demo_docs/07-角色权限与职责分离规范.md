# 角色权限与职责分离规范

> 适用版本：全版本通用 ｜ 文档类型：操作手册

## 1. 核心角色与不相容职责分离

为满足企业财务内控要求，系统预设四类岗位边界，严禁一人兼任审批与出纳打款全流程：

- **报销申请人（普通员工）**：仅可管理本人发票池、发起报销单、查看本人单据与工单。
- **部门审批人**：审批本部门单据的业务真实性与预算合理性。
- **财务复核岗**：审核数电发票合规性、进项税额抵扣规则、会计科目映射及月度关账。
- **出纳付款岗**：执行银企直连付款批次提交、处理银行退票重发，无权修改报销单金额与科目。
- **系统管理员**：维护组织架构、用户启用/禁用、费用科目及客户服务顾问租户授权。

## 2. 员工离职与账号即时禁用

员工离职或调岗时的标准处理步骤：

1. 管理员进入「系统管理 → 用户管理」，找到该员工账号并点击「禁用」；
2. **即时失效机制**：后端每次请求均查库校验账号启用状态，点击禁用后该员工已持有的登录会话立即失效，无法再发起报销或查看企业资料；
3. **严禁物理删除离职账号**：根据《会计档案管理办法》，历史报销单、审批签名记录与关联数电发票必须完整留存备查，因此系统不支持物理删除已有业务单据的账号；
4. 若离职员工名下仍有审批中的单据，由部门主管或财务管理员执行工作交接转办。

## 3. 多租户与外部财务顾问授权

平台支持驻场/售后财务顾问按授权范围协助企业排查异常工单：
- 财务顾问只能在管理员通过「客服授权」明确分配某家企业租户后，才能查看该租户的工单与私有费控内控制度；
- 撤销租户授权后，下一秒请求立即返回无权限拦截。
