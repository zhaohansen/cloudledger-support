# 银企直连付款与退票处理手册

> 适用版本：全版本通用 ｜ 文档类型：操作手册

## 1. 银企直连付款流程

标准流程：`财务复核通过 → 出纳生成付款批次 → 银行网银复核签章 → 扣款回执同步 → 扣减待付台账`。

1. 出纳在「资金结算 → 待付款单据」勾选已终审通过的报销单或对公付款单。
2. 选择付款企业银行基本户或一般户，生成银企直连付款批次单。
3. 提交指令至银行前置机，经网银 U 盾授权放行后，银行完成扣款并回传电子回单。
4. 系统收到银行「交易成功」终态回执后，才将报销单更新为「已支付」，并正式核销对应预算额度。

## 2. 付款账户与可用资金校验

系统默认禁止超付款计划或账户余额不足强行发报。如提示「付款批次校验未通过」或「可用结算额度不足」：

- 在「资金结算 → 银行账户监控」核对付款账户状态及当日单笔/累计限额；
- 检查收款人开户行 **12 位联行号**（跨行转账必填）与收款户名是否包含生僻字或半角括号；
- 确认该笔报销单未被其他出纳员加入另一个处理中的付款批次。

## 3. 银行退票与付款失败排查

若银行打款后出现「银行退票」（常见原因：收款卡号已注销、户名与账号不符、二类卡超日限额、联行号错误）：

1. 银行退票回执同步后，单据状态由「支付中」自动变更为「支付退票」；
2. **注意预算与台账状态**：在退票重发或作废前，原报销单占用的部门预算额度仍保持锁定（不会因为银行退票而自动退回可用预算池），以防员工在换卡重发期间预算被其他单据抢占；
3. 如确认收款卡信息有误需重发，员工在「我的报销 → 收款卡变更」修正银行卡号与开户行后，由出纳在「资金结算 → 退票重发」重新发起支付；
4. 如确认本次业务取消不再支付，需由财务执行「退票关闭并冲销单据」，冲销完成后预占的部门预算额度才会正式释放。
