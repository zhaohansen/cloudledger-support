# 版本更新说明 v2.3

> 适用版本：v2.3 ｜ 文档类型：版本说明

## 一、核心新增能力

### 1. 移动端拍照 OCR 识票与数电 XML 混采
新增移动端拍照 OCR 自动识票能力，支持纸质车票、过路费票及数电票版式截图拍照入池，并与国家税务总局数电发票 XML 结构化解析共用同一套 20 位票号查重机制。

### 2. 预算超支一键生成追加调整单
报销单提交审批触发预算不足时，可点击「生成追加单」，系统按超支差额自动生成关联预算追加调整单。**注意**：该预算调整单必须经过预算管理员与财务负责人二次审核通过后，新增预算额度才会正式生效。

### 3. Excel 导入失败导出错误原因明细
科目映射表、期初预算表导入校验失败后，页面提供「下载错误原因明细表」按钮，导出的文件在原表最后一列逐行写明错误行具体错误原因，无需再像 v2.2 那样逐行人工盲查。

## 二、重要规则变更

- **预算冻结时机变更**：报销单草稿保存后不再锁定部门可用预算，改为正式点击「提交审批」时才校验并冻结对应额度。
- **银企直连回单归档**：银行打款成功后自动拉取 PDF 电子回单挂载至报销单附件区。
- **报销单列表筛选**：新增「待退票重发」快捷筛选条件。

## 三、v2.2 与 v2.3 主要差异对照

| 功能点 | v2.2 | v2.3 |
| --- | --- | --- |
| 票据采集方式 | PC 端上传 XML/PDF + 手工补录 | PC 端上传 + 移动端拍照 OCR 识票 |
| 报销冻结预算时机 | 保存草稿即冻结可用预算 | 提交审批时才冻结可用预算 |
| 预算超支追加处理 | 预算员手工新建预算调整单 | 报销页一键生成追加调整单（二次审核生效） |
| Excel 导入报错提示 | 仅提示失败行号 | 支持下载含具体错误原因的错误行明细表 |
