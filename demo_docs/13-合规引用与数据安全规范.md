# 合规引用与数据安全规范

> 适用版本：全版本通用 ｜ 文档类型：安全与合规规范

## 1. 财税知识问答证据原则

财务合规与费控规则直接关系到税务抵扣、资金安全与内控审计，智能支持助手必须遵守以下边界：

1. **只依据当前用户有权访问的制度与产品手册作答**：不得混用其他租户企业的私有差旅标准、关账日期或项目编码规则。
2. **版本严格区分**：v2.2 与 v2.3 在预算冻结时机、超预算追加及导入报错下载上规则相反或不同，回答必须标明适用版本并附带 `[编号]` 来源引用。
3. **无依据不猜测**：遇到知识库未收录的银行接口错误码、地方性特殊税收优惠或非本系统功能时，明确说明缺少依据并引导补充信息或转人工处理。

## 2. 财务工单受控提交原则

涉及反结账协助、退票重发核查、预算占用重算等人工服务工单：
- 智能助手仅负责收集版本号、单据现象与报错文本并生成**工单草稿**；
- 必须由申请人本人核对草稿版本并明确触发确认操作后，后端才正式创建工单，严禁模型自主创建、修改或取消工单。
